1. HTTP Response Analysis

HTTP/1.1 200 OK
Date: Mon, 01 Apr 2026 10:00:00 GMT
Content-Type: text/html
Content-Length: -150
Connection: keep-alive
Identify Invalid Fields
Content-Length is invalid because HTTP headers cannot have negative values.
Content-Length Issue
The browser uses Content-Length to determine the size of the response body. A negative value may prevent proper rendering of the webpage.
Status Code Analysis
Although 200 OK indicates success, the invalid header makes the response technically incorrect.
Suggested Correction
Replace Content-Length: -150 with a positive value such as Content-Length: 150.

2. DOM Structure Analysis

<html>
<head>
<title>Test Page</title>
</head>
<body>
<div>
<p>Hello World
</div>
</body>
</html>
Missing Elements
The paragraph tag is not properly closed.
Browser Interpretation
Modern browsers automatically close missing tags whenever possible.
Rendering Impact
The webpage may display correctly but does not follow HTML standards.
Suggested Correction
Add the missing </p> tag before the closing div tag.

3. GET vs POST in Login System

Method URL Visibility Security
GET /login?user=admin Visible Low
POST /login Hidden Moderate

Data Transmission
GET sends data through URLs whereas POST sends data through the request body.
Suitable Method
POST is recommended for login systems because credentials are not visible in the address bar.
Security Risks
GET requests expose sensitive information in browser history and server logs.
Best Practices
  • Use POST requests.
  • Use HTTPS.
  • Use secure password hashing.
  • Implement session management.

4. HTML Code Inspection

<!DOCTYPE html>
<html>
<head>
<title>Sample</title>
</head>
<body>
<h1>Welcome
<p>This is a paragraph
<img src="image.jpg">
</body>
</html>
Missing Tags
The closing tags for h1 and paragraph elements are missing.
Image Tag Issues
The image element should include an alt attribute for accessibility purposes.
Browser Handling
Browsers attempt to automatically correct minor HTML errors.
Correct Version 
<h1>Welcome</h1>

<p>This is a paragraph.</p>

<img src="image.jpg"
alt="Sample Image">

Communication Process
The browser communicates with the server through DNS resolution, HTTP requests, and response rendering mechanisms.
Possible Delays
Network latency, DNS lookup time, server response time, and browser rendering may introduce delays.
Role of DNS
DNS converts domain names into IP addresses to establish communication with web servers.
Performance Optimization
  • DNS Caching
  • Browser Caching
  • Content Delivery Networks (CDNs)
  • Compressed Web Resources
  • Optimized Server Responses
